# Release notes

The "What's new" text pasted into Play Console for each release. Mind the
character limit: 500 characters per language. Reefy ships English and Turkish,
so both listings need a note; the Turkish text is written to read natively, not
translated word for word.

## 1.2.4 (versionCode 11) — first production release

This is the build that has been on the closed-testing track since 2026-08-26.
It is the first one that reaches the production track, so the note introduces
the game instead of listing a changelog.

### en-US

```
Welcome to Reefy — a calm aquarium you keep in your pocket.

• 100 fish species to collect, from common tetras to the Golden Arowana.
• 25 aquariums to unlock, each with its own biome and light.
• 80 pieces of decor to place wherever you like.
• Eggs, daily quests, streak gifts and the Coral Festival.
• Your reef keeps earning while you are away — and nothing ever dies.

Sign in with Google Play Games to back your reef up to the cloud and enter the
global ranking.
```

## Earlier builds (closed testing only)

These never reached a production listing, so they never needed a store note.
They are kept here for the record.

- **1.2.4 / versionCode 11** — fixed the entitlement check on a wiped install
  (`pm clear` now restores Remove Ads at launch, without the restore button);
  HUD rework onto a single row.
- **1.2.3 / versionCode 10** — Remove Ads purchase and restore.
- **1.2.2 / versionCode 9** — income cap fix, test-device recognition, mobile
  layout fixes for the system navigation bar and the top row.
- **1.2.0 / versionCode 8** — rebuilt aquarium screen, global ranking, and the
  ad recovery (the UMP consent step no longer fails permanently for a session).
