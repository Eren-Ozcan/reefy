# reefy

## Store / Marketing Assets

Marketing assets like store listings, feature graphics, icons, and screenshots
**are never committed to this public repo**. `*.png` at the repo root is already
covered by `.gitignore` (e.g. project-root screenshots), and beyond that:

1. Local, gitignored copy: `docs/store-assets-originals/`.
2. Private backup repo: `C:\Projects\pictures\reefy\` (a local clone of the
   private `Eren-Ozcan/pictures` repo) — copied there and committed+pushed in
   that repo.

### The one exception: `docs/readme/`

Agreed deliberately on 2026-08-24. `docs/readme/*.png` is committed to this repo
and is exempted in `.gitignore`. It holds the three images the README shows at
the top, and nothing else — a README with no picture of the game is a README
nobody reads, and the rule above would otherwise leave it permanently empty.

Rules for that folder:

- Three images, kept small (270px wide, ~35 KB each). They live in git history
  forever, so a full-size store plate does not belong there.
- Regenerated by `node tools/make-readme-shots.mjs`, which cuts them from the
  gitignored store screenshot set rather than capturing separately — so the
  README can never drift to a different build than the store listing.
- A promo video or GIF is the same decision and has not been made yet. Do not
  commit one on your own; ask.

Everything else — feature graphics, store plates, the icon, captioned sets —
stays out, exactly as above.
